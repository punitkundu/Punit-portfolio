PUNIT KUNDU - CRICKET PORTFOLIO
================================

Folder:
  index.html   -> main portfolio page
  assets/      -> all photos (your cutout, stadium, balls, project screenshots)

How to open:
  1. Unzip this folder.
  2. Double-click index.html (needs internet once for the Google Fonts).

How to put it online (free):
  - Vercel: vercel.com -> Add New -> Project -> upload this folder.
  - Netlify: app.netlify.com/drop -> drag and drop this folder.
  - GitHub Pages: upload the files to a GitHub repository -> Settings -> Pages.

How to change things:
  - Open index.html in VS Code / any text editor.
  - Email: search for kundupunit927@gmail.com
  - LinkedIn link: search for linkedin.com/in/
  - Photos: replace files inside assets/ keeping the same names.
